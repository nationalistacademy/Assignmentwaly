❓ Question 1 (Long Question - 8 marks): Define Matrix. Explain the types of matrices with at least one example for each.

📌 Answer: A matrix is a rectangular arrangement of numbers, symbols, or expressions arranged in rows and columns. It is denoted by a capital letter (e.g., A). It is a fundamental tool in business mathematics for solving systems of linear equations, input-output analysis, and data representation.

Types of Matrices with Examples:

  • Row Matrix: A matrix with only one row. Example: A = [2 5 8]
  • Column Matrix: A matrix with only one column. Example: B = [4; 7; 1]
  • Square Matrix: A matrix where the number of rows equals the number of columns. Example: C = |1 2; 3 4| (2x2 matrix)
  • Diagonal Matrix: A square matrix where all non-diagonal elements are zero. Example: D = |5 0; 0 9|
  • Identity Matrix: A diagonal matrix where all diagonal elements are 1. Example: I = |1 0; 0 1|
  • Zero/Null Matrix: A matrix where all elements are zero. Example: O = |0 0; 0 0|
  • Transpose of a Matrix: Obtained by interchanging rows and columns. If A = |a b; c d|, then Aᵀ = |a c; b d|.

🎓 Tutor's Advice: In exams, always draw a proper bracket [ ] or ( ) for matrices. For 8 marks, explain at least 6 types with neat examples. This is a guaranteed question!

❓ Question 2 (Long Question - 8 marks): A retailer bought 50 units of a product at Rs. 400 per unit. He marked the price 30% above the cost price and offered a 15% discount on the marked price. Calculate:
  • (a) The marked price per unit.
  • (b) The selling price per unit after discount.
  • (c) The total profit or loss on the whole sale.
  • (d) The percentage of profit or loss.

📌 Solution (Step-by-Step):

  1. Given Data:
    • Cost Price per unit (C.P) = Rs. 400
    • Mark-up on Cost Price = 30%
    • Discount on Marked Price = 15%
    • Total Units = 50
  2. (a) Marked Price (M.P):
    M.P = C.P + (30% of C.P) = 400 + (30/100 * 400) = 400 + 120 = Rs. 520 per unit.
  3. (b) Selling Price (S.P) after discount:
    Discount amount = 15% of M.P = (15/100) * 520 = Rs. 78.
    S.P = M.P - Discount = 520 - 78 = Rs. 442 per unit.
  4. (c) Total Profit or Loss:
    Total C.P = 50 * 400 = Rs. 20,000.
    Total S.P = 50 * 442 = Rs. 22,100.
    Since S.P > C.P, it's a Profit. Total Profit = 22,100 - 20,000 = Rs. 2,100.
  5. (d) Profit Percentage:
    Profit % = (Profit / Total C.P) * 100 = (2,100 / 20,000) * 100 = 10.5%.
💡 Examiner's Note: Always mention the formulas like M.P = C.P + Gain. Show your calculations clearly. This is a high-scoring question because it tests multiple concepts in one go.
❓ Question 3 (Short Question - 5 marks): Solve the system of linear equations using the substitution method: 2x + y = 10 and x - y = 2.

📌 Solution:

Given equations:
(1) 2x + y = 10
(2) x - y = 2

Step 1: From equation (2), we can write: x = 2 + y.

Step 2: Substitute this value of x into equation (1):
2(2 + y) + y = 10 → 4 + 2y + y = 10 → 4 + 3y = 10 → 3y = 6 → y = 2.

Step 3: Substitute y = 2 into x = 2 + y → x = 2 + 2 = 4.

Answer: x = 4, y = 2.

Verification: Put values in equation (1): 2(4) + 2 = 8 + 2 = 10. Correct!

❓ Question 4 (Long Question - 10 marks): Find the inverse of the following matrix using the adjoint method: A = | 2 3 ; 1 4 |

📌 Solution (Step-by-Step):

For a 2x2 matrix A = |a b; c d|, the inverse A⁻¹ = (1 / det(A)) * |d -b; -c a|.

Step 1: Calculate Determinant (det)
det(A) = (a*d) - (b*c) = (2*4) - (3*1) = 8 - 3 = 5.

Step 2: Find the Adjoint Matrix
The adjoint of A = |d -b; -c a| = |4 -3; -1 2|.

Step 3: Apply Formula for Inverse
A⁻¹ = (1/5) * |4 -3; -1 2| = |4/5 -3/5; -1/5 2/5|.

Final Answer: A⁻¹ = |0.8 -0.6; -0.2 0.4|.

🔑 Important Tip: Always verify by multiplying A * A⁻¹. The result should be the Identity Matrix (I). This is a common practice to check your answer in exams.
❓ Question 5 (Short Question - 5 marks): If the sum of the first 5 terms of an arithmetic sequence is 50 and the first term is 6, find the common difference.

📌 Solution:

Formula for sum of first n terms of an Arithmetic Progression (A.P): Sₙ = n/2 * [2a + (n-1)d].

Given: n = 5, S₅ = 50, a = 6.

Substitute values: 50 = 5/2 * [2(6) + (5-1)d] → 50 = 2.5 * [12 + 4d] → 50 / 2.5 = 12 + 4d → 20 = 12 + 4d → 20 - 12 = 4d → 8 = 4d → d = 2.

Answer: The common difference is 2. The sequence is: 6, 8, 10, 12, 14.

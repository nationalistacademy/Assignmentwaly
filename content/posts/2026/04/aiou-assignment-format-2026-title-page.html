AIOU Assignment Format 2026 – Title Page, Margins, Fonts Guide

Complete guide to AIOU assignment format 2026. Title page template, margin settings, font requirements, and submission guidelines for high marks.

Why Format Matters for Marks

Proper format gives first impression. 5-10% marks depend on presentation. Examiner prefers well-formatted assignments.

Assignment Format Requirements

Paper Size and Margins

Paper Size: A4 (8.5 × 11 inches)
Top Margin: 1 inch (2.54 cm)
Bottom Margin: 1 inch (2.54 cm)
Left Margin: 1.5 inches (3.81 cm) – for binding
Right Margin: 1 inch (2.54 cm)

Font Settings

Font Style: Arial or Times New Roman
Font Size: 12pt for body text
Font Size: 14pt Bold for headings
Font Size: 16pt Bold for main title
Line Spacing: 1.5
Paragraph Spacing: 6pt after each paragraph
Text Color: Black only

Page Numbers

Position: Bottom center or bottom right
Start from: First page of content (not title page)
Format: Page 1, 2, 3... or 1/10, 2/10

Title Page Format (Must Include)

ALLAHAMA IQBAL OPEN UNIVERSITY ISLAMABAD
(Faculty of [Your Faculty Name])

COURSE: [Course Name]
COURSE CODE: [e.g., 1423]
SEMESTER: [Spring/Autumn 2026]

ASSIGNMENT No. [1/2/3]


SUBMITTED TO: [Tutor Name]
SUBMITTED BY: [Your Name]
ROLL NUMBER: [Your Roll Number]
REGISTRATION NUMBER: [Your Reg Number]
DATE OF SUBMISSION: [DD/MM/YYYY]

Assignment Structure

1. Table of Contents (if assignment has multiple questions)
2. Question 1
   - Answer (500-800 words)
   - Diagrams if applicable
3. Question 2
   - Answer (500-800 words)
4. Question 3
   - Answer (500-800 words)
5. References/Bibliography
   - AIOU Textbook (Page X-Y)
   - Additional books or websites

Handwritten Assignment Format

If writing by hand (some programs allow):
- Use blue pen for answers
- Use black pen for headings/drawings
- Write on one side of paper only
- Leave 1-inch margin on left side
- Write neatly and legibly
- No cutting or overwriting (use corrector pen if mistake)

Typed Assignment Format (MS Word Settings)

Step 1: Open MS Word → Layout → Margins → Custom Margins (set as above)
Step 2: Home → Font → Arial 12pt
Step 3: Home → Paragraph → Line Spacing 1.5
Step 4: Insert → Page Number → Bottom Center
Step 5: Save as PDF before printing

Common Format Mistakes

❌ Using colorful text or highlights
❌ Different fonts in same assignment
❌ No page numbers
❌ Missing title page
❌ Wrong margin settings
❌ Handwriting not readable
✅ Always follow standard format for better marks

Frequently Asked Questions

Can I use colored paper for assignment?

No. Use plain white A4 paper only. Colored paper may be rejected.

Do I need to bind the assignment?

Simple stapling is enough. Spiral binding not required but acceptable.

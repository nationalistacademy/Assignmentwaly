🔥 AIOU 9231 Web Design & Development – حل شدہ اندازہ شدہ گیس پیپر (بہار 2026)

AIOU کورس کوڈ 9231 (Web Design and Development) بی ایس کمپیوٹر سائنس اور آئی ٹی کے طلباء کے لیے ہے۔ اس میں HTML ٹیبلز، فارمز، CSS باکس ماڈل، ریسپانسیو ڈیزائن، میڈیا کوئریز اور ویب ہوسٹنگ شامل ہیں۔ یہ پوری طرح حل شدہ گیس پیپر ہے، جو پچھلے 5 سال کے پیپر پیٹرن پر مبنی ہے۔ امتحان سے پہلے ضرور پڑھیں۔

⭐ امتحانی حکمت عملی: 70% سوالات HTML Tables, CSS Box Model, Responsive Web Design اور Forms سے آتے ہیں۔ کوڈ کی مثالوں کے ساتھ مشق کریں۔

📝 سیکشن A: ایڈوانسڈ HTML اور ملٹی میڈیا

Q1. HTML ٹیبلز – ٹیگز، colspan اور rowspan

جواب: HTML ٹیبلز ڈیٹا کو قطاروں اور کالموں میں ظاہر کرتی ہیں۔ اہم ٹیگز:

  • <table> – کنٹینر
  • <tr> – ٹیبل رو
  • <td> – ڈیٹا سیل
  • <th> – ہیڈر سیل (بولڈ)

colspan اور rowspan: یہ سیلز کو ضم کرتے ہیں۔ colspan="2" سے دو کالم افقی طور پر merge ہوتے ہیں، rowspan="2" سے دو قطاریں عمودی طور پر۔ مثال:

<table border="1">
 <tr><th colspan="2">Merged Header</th></tr>
</table>

Q2. HTML فارمز – ضروری عناصر اور name attribute

جواب: فارم صارف سے ڈیٹا لینے کے لیے ہوتے ہیں۔ اہم ان پٹ ٹائپس: text, password, email, radio, checkbox, select, textarea, submit button۔ name attribute کی اہمیت: یہ کلید کا کام کرتا ہے۔ سرور کو ڈیٹا پہنچانے کے لیے name کے بغیر ویلیو نہیں پہنچ سکتی۔

<input type="text" name="student_name">
<input type="submit" value="بھیجیں">

Q3. ملٹی میڈیا انٹیگریشن – ویڈیو، آڈیو اور فال بیک

جواب: HTML5 نے <video> اور <audio> ٹیگز متعارف کرائے۔ فال بیک (fallback) وہ متن یا Flash ہوتا ہے جو براؤزر نہ چلانے پر دکھایا جائے۔ فارمیٹس میں MP4, WebM, Ogg شامل ہیں۔

<video controls>
 <source src="course.mp4" type="video/mp4">
 آپ کا براؤزر ویڈیو سپورٹ نہیں کرتا۔
</video>

🎨 سیکشن B: Cascading Style Sheets (CSS)

Q4. CSS کی بنیادی باتیں – Inline, Internal, External

جواب: CSS دستاویزات کی پیشکش (presentation) کنٹرول کرتی ہے۔

  • Inline CSS: style attribute کے اندر → خاص element کے لیے، بڑی ویب سائٹ کے لیے مناسب نہیں۔
  • Internal CSS: <style> ٹیگ میں head سیکشن میں → ایک پیج کے لیے بہتر۔
  • External CSS: علیحدہ .css فائل، <link> سے منسلک → بڑی ویب سائٹس کے لیے بہترین (دوبارہ استعمال، آسان مینٹیننس)۔

Q5. CSS باکس ماڈل – Content, Padding, Border, Margin

جواب: ہر عنصر باکس کی شکل میں ہوتا ہے:

  • Content – اصل مواد
  • Padding – content اور border کے درمیان (اندر سے فاصلہ)
  • Border – padding اور content کے گرد لکیر
  • Margin – باکس کے باہر دوسرے عناصر سے فاصلہ

کل چوڑائی = width + padding-left/right + border-left/right + margin-left/right

.card { width: 200px; padding: 15px; border: 3px solid green; margin: 10px; }

Q6. سلیکٹرز (ID vs Class) اور پراپرٹیز

جواب: ID selector (#) صرف ایک منفرد عنصر کے لیے، مثال: #header۔ Class selector (.) کئی عناصر کے لیے، مثال: .btn۔ بیک گراؤنڈ کلر اور فونٹ سائز تبدیل کرنے کا طریقہ:

p { background-color: #f0f0f0; font-size: 18px; }

📱 سیکشن C: لی آؤٹ اور جدید ویب اصول

Q7. ریسپانسیو ویب ڈیزائن – Viewport & Media Queries

جواب: RWD سے ویب سائٹ موبائل، ٹیبلیٹ اور ڈیسک ٹاپ پر اچھی دکھائی دیتی ہے۔ Viewport میٹا ٹیگ موبائل براؤزر کو پیمانہ کنٹرول کرنے کا بتاتا ہے:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Media Queries: مختلف اسکرین سائز کے لیے مختلف CSS لاگو کرتے ہیں۔ مثال:

@media (max-width: 600px) { body { font-size: 14px; } }

Q8. ہائپر لنکس – Absolute vs Relative URLs اور انٹرنل لنکس

  • Absolute URL: مکمل ایڈریس (https://assignmentwaly.blogspot.com/example) – بیرونی ویب سائٹ کے لیے۔
  • Relative URL: موجودہ پیج سے تعلق (images/photo.jpg) – اپنی ویب سائٹ کے اندر۔
  • انٹرنل لنک (اسی صفحہ پر جمپ): <a href="#sectionB">جائیں</a> اور <h2 id="sectionB">...

Q9. ویب ہوسٹنگ اور پبلشنگ – Domain, Hosting, FTP

جواب: ویب سائٹ لائیو کرنے کے مراحل:

  1. ڈومین نام – منفرد ایڈریس (مثلاً assignmentwaly.blogspot.com)
  2. ویب ہوسٹنگ سرور – ویب سائٹ فائلیں ذخیرہ کرنے والا کمپیوٹر
  3. FTP (File Transfer Protocol) – فائلیں اپ لوڈ کرنے کا ٹول (FileZilla)
  4. فائلیں اپ لوڈ کریں → ویب سائٹ دنیا بھر میں لائیو ہو جاتی ہے۔

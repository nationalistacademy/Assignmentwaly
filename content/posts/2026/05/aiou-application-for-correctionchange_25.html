📌 When is Program Change/Correction Allowed? (Tabdeeli e Shoba)

AIOU admissions rules ke mutabiq aap darj-zail situations me program tabdeeli ki request bhej sakte hain:

  • ✅ Mistake at Admission Time: Admission portal par apply karte waqt ghalti se BA General ke bajaye BA Library Science select ho gaya ho.
  • ✅ Eligibility Correction: University evaluation team ne eligibility criteria (marks/CGPA delay) ki waja se aapko program change karne ki direct advice ki ho.
  • ✅ Program Switch Request: Aap 2-years Associate Degree Program se 4-years BS program me first semester ke dauran shift hona chahte hon.
  • ✅ Specialization Correction: MBA ya B.Ed programs me specialization fields (jaise Science Education se Special Education) badalni hon.
Program Tabdeeli Ki Ahem Tarikh (Deadline): Program tabdeeli sirf Admission Confirmation ke 30 se 45 din ke andar hi allowed hoti hai. Semester exams shuru hone ke baad ya assignment submission dates guzray ke baad koi bhi case process nahi kiya jata.

📝 Step‑by‑Step Procedure for Program Change & Credit Transfer

  1. Download & Print Form: Upar diye gaye official green button par click kar ke PDF application form save karein aur hard-copy print out lein.
  2. Fill Educational Credentials:
    • Apna Mukammal Naam, CNIC, Phone Number, and Student ID/Enrollment Number darj karein.
    • Incorrect Current Program: Wo program likhein jo ghalti se CMS portal par show ho raha hai.
    • Correct / New Required Program: Target course/program ka mukammal naam aur code likhein jis me aap shift hona chahte hain.
  3. Attach Attested Academic Records:
    • Attested copy of Student CNIC / Matric / Inter certificates (proof of basic eligibility).
    • Portal registration receipt ya original processing challan slip.
    • Undertaking Certificate: Rs. 50 ya Rs. 100 ke stamp paper par likha hua bayan-e-half (Undertaking) ke aap is change ke tamam university rules aor exams outcomes ke khud zimedar honge.
  4. Submit the Fee & Fee Difference:
    • Standard Program Change Fee: Rs. 500/- se Rs. 1,000/- challan structure.
    • Program Fee Difference: Agar naye program ki fee purane program se zyada hai, to donon fees ke darmiyan jo difference amount (e.g. Rs. 2,000 extra) ho gi, wo extra challan slip ke zariye pay karni hogi.
  5. Registrar Admissions Cell Submission:
    • Tamam attested documents, processing fee slip aur difference challan ko envelope me dal kar is address par register courier karein: Director of Admissions, Program Change/Admissions Section, Block No. 3, Sector H-8, AIOU Main Campus, Islamabad – 44000.
Pro Tip for Credit Transfer (Course Exemption): Agar aapne purane program me 1-2 subjects clear kar liye hain, to program change ke sath Credit Transfer form lazmi bhein takay clear shuda subjects naye course me shamil ho sakein aur aapka semester/saal zaya hone se bach jaye!

❓ Frequently Asked Questions – Program Correction Support Desk

🔹 Kya main 2nd ya 3rd semester me ja kar program change kar sakta hon?
Nahi. AIOU policy ke mutabiq program tabdeeli sirf 1st semester ke pehle 45 din ke andar hi allowed hoti hai. Is ke baad program tabdeel karne ke liye purana admission cancel karwa ke new admission lena parta hai.
🔹 Agar main program change karon to kya meri purani assignments aor books zaya ho jayein gi?
Agar naye program ke subjects mukhtalif hain (jo ke zyadatar hote hain), to purani kitabein aur assignments zaya ho jayein gi aur aapko naye codes ki assignments fresh likh kar submit karni hongi.
🔹 Fee difference calculate karne ka kya tareeqa hai?
For example, agar aapke purane program (BA) ki fee Rs. 5,000 thi aur naye BS program ki fee Rs. 12,000 hai, to donon ka farq (12,000 - 5,000 = Rs. 7,000) fee difference challan ke zariye pay karna hoga.
🔹 Kya program tabdeeli online CMS portal se ho sakti hai?
Nahi. Program change administrative levels par process hota hai jahan educational certificates key verification lazmi hoti hai. Is liye complete document package raw courier ke zariye central campus bhejna parta hai.

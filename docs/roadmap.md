# Assignmentwaly publishing roadmap

**Primary mission:** Build a trustworthy, original, mobile-first educational resource for AIOU learners across Pakistan and make the live Blogger site genuinely ready for AdSense review. Approval and rankings are not guaranteed. See [the public-site audit](ADSENSE-READINESS-AUDIT.md).

## Product rule
Assignmentwaly is the assignment-article website. AIOU Coaching is the destination for AIOU student tools, study support and guess papers. Assignmentwaly should link visitors to relevant AIOU Coaching resources rather than host duplicate public tools.

## Phase 1 — Site roles and navigation
- [x] Reposition Assignmentwaly homepage around assignment articles and student resources.
- [x] Route tool discovery cards and calls to action to https://aioucoaching.blogspot.com/.
- [ ] Add direct links from assignment articles to matching AIOU Coaching tool pages when those page URLs are confirmed.
- [ ] Build the Study Planner, Citation Helper and MCQ Practice Maker in the AIOU Coaching project/site.

## Phase 2 — Article quality
- [x] Define original article and companion-resource publishing gate.
- [x] Define supervised multi-agent roles and human approval.
- [ ] Build a reusable article brief and source register template.
- [ ] Add correction history and visible review dates for changeable content.
- [ ] Review assignment articles for accuracy, originality, academic integrity and useful supporting resources.

## Phase 3 — Quality and growth
- [ ] Mobile performance and accessibility checks in CI.
- [ ] Structured data and metadata validation where appropriate.
- [ ] AIOU course/resource taxonomy backed by official sources.
- [ ] Privacy review before adding accounts, cloud sync, uploads or analytics.

## Release gates
Do not publish an article before its relevant companion resource is functional and tested, sources are verified, content is meaningfully original, mobile/accessibility checks pass, and a human editor approves the package. Do not add paid APIs as a requirement for core tools.

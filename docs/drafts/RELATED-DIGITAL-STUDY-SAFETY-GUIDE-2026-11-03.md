<article style="max-width:900px;margin:0 auto;padding:8px;line-height:1.75;font-family:Arial,sans-serif;overflow-wrap:anywhere;">
<p>Online learning often involves PDFs, word-processing files, learning portals, email and shared links. A simple digital routine can help students keep their work organised and reduce avoidable account and file problems. This guide offers general digital-literacy advice; always follow the official instructions of your own institution and the software you use.</p>

<h2>1. Organise study files</h2>
<p>Create a small folder structure that is easy to understand. For example, use one main folder for a semester, then separate folders for each course, lecture notes, assignment drafts and submitted work. Use descriptive file names such as <code>Course260_UnitNotes_2026-11-03.docx</code>. Avoid vague names such as <code>final-final-new2.docx</code>.</p>

<h2>2. Keep more than one copy</h2>
<p>A device can be lost, damaged or infected by malware. Keep a second copy of important study work on a separate trusted storage location, such as an institution-approved cloud service or an external drive. Check occasionally that the backup opens correctly. A synchronised folder is useful, but it is not always a complete backup if accidental deletion is synchronised too.</p>

<h2>3. Use safe account habits</h2>
<ul>
<li>Use a unique, long password or passphrase for each important account.</li>
<li>Use a reputable password manager if it is suitable for your situation.</li>
<li>Enable multi-factor authentication where available.</li>
<li>Never share passwords, one-time codes or recovery codes with another person.</li>
<li>Sign out of shared computers and avoid saving passwords in public browsers.</li>
<li>Keep your operating system, browser and security software updated.</li>
</ul>

<h2>4. Recognise suspicious messages</h2>
<p>Pause before opening an unexpected attachment or link. Check the sender address carefully, look for unusual requests for urgent payment or account verification, and navigate to the official website yourself rather than using a suspicious message link. A familiar logo or a correct-looking display name does not prove that a message is genuine.</p>

<h2>5. Protect your privacy when using shared devices</h2>
<p>Do not leave student portals, email accounts or cloud drives signed in on a public or shared computer. Avoid downloading private documents to a device you do not control. If you must use a shared device, sign out of every account, close the browser and remove locally saved copies where permitted.</p>

<h2>6. Share files carefully</h2>
<p>Before sharing a document, check that it contains only the information the recipient needs. Review sharing permissions and avoid public links for private student records. Use official institutional channels for enrolment details, assignments and personal information. Do not upload another student's work or personal data without permission.</p>

<h2>7. Check a document before submission</h2>
<ol>
<li>Open the saved file and confirm it is not corrupted.</li>
<li>Check the file name and course identifier.</li>
<li>Review headings, page order, spelling and readability.</li>
<li>Confirm that the file type and size match the receiving portal's instructions.</li>
<li>Keep a copy of the final version and any submission confirmation.</li>
</ol>

<h2>Self-check questions</h2>
<ol>
<li>Why should important study files have clear names and folders?</li>

<li>What should you do when an unexpected message asks you to sign in urgently?</li>
<li>Why should file-sharing permissions be checked before sending a document?</li>
</ol>

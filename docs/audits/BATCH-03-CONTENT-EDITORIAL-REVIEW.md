## Executive findings

- The repeated unrelated “Solved Assignment Key” block and generic Spring 2026 deadline table appear on informational pages and subject resources. Remove it from each affected post.
- The admission guide carries dated Spring 2026 deadlines and unsupported fee, tutor-contact and marks claims. It should not be presented as a current admissions guide.

- There are duplicate/overlapping course pages: Code 258 (positions 101 and 108), Code 259 (102 and 107), and ICT/Code 260 (103 and 106). These are merge candidates, not automatic deletions.

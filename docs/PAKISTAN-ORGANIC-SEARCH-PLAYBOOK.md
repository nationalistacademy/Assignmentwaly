# Pakistan-wide organic search playbook

**Goal:** Grow useful non-paid discovery for Assignmentwaly across Pakistan by answering AIOU student tasks accurately. This is a strategy and measurement plan, not a ranking or traffic guarantee.

## 1. National search positioning

Build one strong national resource architecture around AIOU and student tasks. Do not create thin city pages for Karachi, Lahore, Islamabad, Peshawar, Quetta or other cities when the process is the same. Add regional context only when an official process, office, deadline, delivery route or support channel genuinely differs.

Use consistent entity references:
- Allama Iqbal Open University (AIOU).
- Exact programme and qualification names.
- Course code and course title.
- Semester and academic year.
- Official portal names and official notice dates.

## 2. Intent clusters

| Cluster | Example query themes | Content format |
|---|---|---|
| Admissions | AIOU admission, eligibility, programme, last date, fee | Current guide + official notice |
| Student onboarding | admission confirmation, CMS login, books dispatch | Step-by-step troubleshooting |
| Semester operations | tutor, workshop, assignment deadline, submission | Checklist + dated guide |
| Course resources | course code, subject notes, syllabus | Course hub with verified metadata |
| Assignment learning | understand question, structure answer, citations | Learning guide + worksheet |
| Exams | roll number slip, date sheet, past papers, result | Official-route guide + practice |
| Graduation | transcript, degree, verification, correction | Process guide + document checklist |
| Overseas study | overseas AIOU admission, online access, time zone | Audience-specific guide |

Do not target every query with a separate near-identical page. Group queries by the task a page can fully solve.

## 3. On-page optimization

- One clear primary intent per URL; use natural variants only where they fit.
- Unique title and description that explain the page's actual benefit.
- Put the direct answer and eligibility/scope near the top.
- Use descriptive H2/H3 headings, short paragraphs and useful tables.
- Add internal links to the preceding and following student task.
- Cite the exact official notice or portal page for changing facts.
- Show a last-checked date and update it only after a real review.
- Add descriptive image alt text; compress images and avoid decorative image overload.
- Keep canonical URLs stable; no permalink changes without a documented migration and redirect plan.
- Add only valid structured data that matches visible page content.

## 4. Pakistan-specific relevance

- Use PKR only when discussing a verified fee or payment amount.
- State Pakistan Standard Time when a deadline/time-zone distinction matters.
- Explain Pakistan Post or regional delivery only when supported by current official information.
- Do not infer that every city has a separate AIOU procedure.
- Make overseas guidance distinct only where eligibility, document handling or timing differs.
- Keep Urdu and English terminology consistent; explain official English portal labels in plain Urdu where helpful.

## 5. Internal-link architecture

Create a crawlable hierarchy:
- Homepage → student task hubs.
- Task hub → detailed guides.
- Programme/course hub → relevant course-code resources.
- Assignment guide → concept explanation, citation guidance and companion formatter.
- Exam guide → syllabus, practice set and official exam route.
- Every guide → one logical next action and a correction/contact route.

Assignmentwaly should link to relevant AIOU Coaching tools when they directly help the task. Do not duplicate the same article or tool on both sites merely to occupy more search results.

## 6. Generative search readiness (GEO)

- Answer factual questions directly and state the audience/scope.
- Attribute facts to primary sources and include dates.
- Use clear definitions, consistent entities and descriptive headings.
- Distinguish official policy from editorial explanation.
- Make uncertainty visible; do not fill gaps with speculation.
- Keep authorship, review process and corrections transparent.
- Do not fabricate expert credentials, institutional affiliation, testimonials, reviews or statistics.
- Do not promise AI Overview placement, chatbot citations or search rankings.

## 7. Measurement plan

Use the verified Google Search Console property as the source of organic search performance. Capture a baseline before prioritizing updates.

Track:
- Search clicks and impressions.
- CTR and average position, interpreted with query/page context.
- Queries and landing pages by intent cluster.
- Country and device segments; confirm Pakistan performance rather than assuming it.
- Indexing status and canonical selection.
- Page-level engagement only where analytics are correctly configured.

Compare consistent 28-day and 90-day windows. Annotate content changes and seasonal AIOU admission/exam periods. A zero-row data pull is not evidence of zero traffic until the property, permissions, date range and dimensions are checked.

## 8. 90-day implementation sequence

### Days 1–15: Baseline and triage
- Confirm Search Console property and sitemap status.
- Reconcile the 190-URL archive manifest with live URLs.
- Sample each journey cluster and prioritize high-risk time-sensitive claims.
- Build the URL-level editorial register.

### Days 16–45: Refresh high-intent pages
- Improve the most useful admission, onboarding, assignment, workshop and exam guides.
- Add dated official sources and next-step internal links.
- Fix broken links, title/description gaps and confusing navigation.
- Record every change and preserve existing URLs.

### Days 46–75: Fill genuine gaps
- Publish only missing guides validated by student needs and query data.
- Add useful course/programme hubs where the archive supports them.
- Link to working AIOU Coaching companion tools.
- Review mobile usability, accessibility and page performance.

### Days 76–90: Measure and refine
- Compare Search Console performance to baseline.
- Identify pages with impressions but weak CTR or mismatched intent.
- Investigate indexing/canonical issues before creating more pages.
- Update outdated facts and document corrections.

## 9. Quality safeguards

No mass city doorway pages, keyword-stuffed titles, fabricated search volumes, copied notes, unauthorized PDFs, fake reviews, misleading urgency, guaranteed marks, or scaled near-duplicate course pages. Keep ads separate from navigation and downloads. Human editorial approval is required before live publication.
